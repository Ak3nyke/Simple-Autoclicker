A simple **Autoclicker** made in Python with a minimal and modern GUI/UI with 4 preset and a custom CPS value slider/box; it can go from 1 CPS to 10000 CPS.

> Easy Start/Stop with the keybind "F6" _(not customizable at the moment)_.

> Select a preset between **"Slow", "Medium", "Fast" and "Turbo"** or use the slider/box to set your preferred value.

> Feel free to give feedback!

> Feel free to use it however you like it.
